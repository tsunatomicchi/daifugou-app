# 大富豪・チャット併用版 v0.4.0

動作確認済みの「同期修正版 v0.3.2」を基にした表示のみの更新です。
ゲーム画面を左上に固定し、幅60vw・高さ80dvhに収めます。
手札のカードを拡大し、52枚のカード隅の数字を18→24、
スートの倍率を0.29→0.46に変更しています。
右40%と下20%は部屋のチャット・操作に使える空間として空けます。

## 再生成

```sh
python3 plugin-ui/build.py
python3 plugin-ui/test_layout.py
```

ビルドはPython標準ライブラリだけを使います。基となるZIPがない場合は
固定コミットから取得し、SHA-256を照合してから使用します。
`layout.css` に画面の追加CSS、`build.py` に52枚のSVGの拡大と梱包処理があります。
配布物は `releases/tsunasapo-daifugou-chatview-v0.4.0-plugin.zip` です。

以前のクラウド作業で作られたReactソースが現在のチェックアウトには
保持されていないため、ゲームの再実装は行わず、公開済みの安定版ZIPを使います。
全JavaScriptが基のファイルと一致することを毎回検証します。
許容する差分はプラグイン内部ID、アセットの参照先、画面上の版名だけです。
宛先チェック・同期・シャッフル・カード選択・ルールを変更しません。
内部IDとファイル名は新しくし、旧版のキャッシュと区別します。
通信チャンネルは安定版の `tsunasapo-daifugou-handroute-v1` を維持します。

ブラウザ確認にはPython Playwrightと `/usr/bin/chromium` が必要です。
梱包した実際のコードを起動し、模擬部屋で3人・10人参加、選択保持、出札、
Module Federationの公開API、画像の読み込みを確認します。
1920×1080、1440×900、1366×768、1280×720、1024×600、910×564で、
左上60%×80%の領域・スクロールなし・カードのクリック範囲を検証します。
実際のメタテルの部屋を使用する試験ではありません。
`mock-room.js` と試験コードは配布ZIPには含めません。

導入するときは旧版を停止し、この版を読み込みます。
名前は `tsunasapo-daifugou-chatview`、内部IDは
`app_f4204b558fa343a292c37968e9c638f50` です。
